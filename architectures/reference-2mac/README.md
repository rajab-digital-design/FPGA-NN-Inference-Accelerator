# 2-MAC reference architecture

This branch preserves a two-lane reference implementation for architecture and cycle-count context. It is not part of the four-way 16.5 ns timing comparison.

## Archived result and evidence

Use the branch-specific GUI project and source list. Do not compare the historical results with the four-way variants unless target device, constraints, and implementation conditions match.

Primary evidence: `project/reference-2mac.xise`. These results are historical tool outputs and were not freshly generated during repository curation. Read the reports and transcripts for the exact run configuration.

## Running this branch

- Open the branch-specific project in `project/` using Xilinx ISE 14.7, or use the supplied scripts in `build/` from an ISE Command Prompt.
- Run branch-specific modelsim `.do` scripts from this branch's root when present.
- Preserve the archived reports and write new outputs to a separate location.
- See [`../../docs/reproduction.md`](../../docs/reproduction.md) for general guidance and limitations.
